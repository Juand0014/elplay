# ElPlay

Mobile-first PWA for softball leagues in the Dominican Republic.

**Code:** English · **UI:** Spanish (`src/i18n/es.ts`) · **No v1/v2** — one product.

## Quick start

```bash
pnpm install
cp .env.example .env
pnpm web
```
